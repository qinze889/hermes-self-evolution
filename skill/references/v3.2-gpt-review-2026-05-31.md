## R1 发现的 12 个严重问题

1. `fetch_aihot()` — `generate_insight({"title": title, "summary": summary})` 缺少 `source` → AI HOT 分支永不命中
2. GitHub/Arxiv 同理，三源分析内容系统性失真
3. Arxiv 429 重试后 `root` 未定义 → `UnboundLocalError`
4. `save_proposals()` dedup 解析格式 `- **action** │ benefit:` 与实际写入 `- **action**\n  - 📈 收益:` 不匹配 → 去重失效
5. dedup 以自然语言 action 文本做精确匹配 → 标题微变就绕过
6. `seen` 在三源函数中各自 load/save → 竞态覆盖风险
7. 所有文件写入非原子 → 中断产生损坏文件
8. Shell 脚本 `2026-*.md` 硬编码 → 跨年静默失效
9. `list_pending_proposals.sh` 未启用 `nullglob` → 空目录伪错误
10. 提案状态机文档与实现不一致（`deferred`/`rolled_back`）
11. `format_report()` 异常完全吞没 → 健康面板静默失效
12. `absorb_learnings.sh` marker 时序不安全

## 修复方案

- **source 缺失**: 三源统一传完整 `fe`/`findings_entry` dict
- **Arxiv root**: `root=None` + `if root is None: continue`
- **dedup**: 改为 URL 标准化去重（`source_url` 去 query/fragment）
- **seen**: `main()` 集中管理，传参数，最后原子写回
- **原子写**: `tmp + os.replace()` 模式
- **Shell**: `20??-??-??.md` + `shopt -s nullglob` + `set -euo pipefail` + `HERMES_HOME`
- **异常吞没**: 全部加 `logger.warning`
- **状态机**: 补 `deferred` 状态流转 + API + UI

## 15 个中等问题

关键词子串误判、标题 bonus 几乎不触发、GitHub score 未 cap、Arxiv `days` 未使用、三源字段不统一、`.env` 文件未用 context manager、多个 `open()` 缺 `encoding="utf-8"`、`except: pass` 吞异常、`update_index()` 子串去重误删、shell 管道对空格不稳妥、`grep -E "^| "` 匹配全行无意义、`absorb` 输出与注释不符
